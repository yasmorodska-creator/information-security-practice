# Звіт аудиту безпеки — Електронний деканат

## 1. Резюме
Проведено комплексний аудит безпеки додатку. Перевірено стійкість до атак, налаштування середовища та захист даних.

## 2. Реалізовані шари захисту (Defense in Depth)

| Шар | Механізм | Практична |
|---|---|---|
| 1. Інфраструктура | Docker Compose, SQLAlchemy ORM, Alembic | №2–3 |
| 2. Автентифікація | Bcrypt хешування, JWT access + refresh tokens | №4–5 |
| 3. Авторизація | RBAC з трьома ролями (admin, teacher, student) | №5 |
| 4. Валідація вводу | Pydantic-схеми, bleach санітизація, CSP, Rate Limiting | №6 |
| 5. Шифрування даних | Fernet AES для PII, зашифровані бекапи | №7 |
| 6. Аудит і моніторинг | audit_log 5W, Brute Force detection, Security Stats | №8 |
| 7. Безпека середовища | Docker non-root, HTTPS, Trivy, Bandit, pip-audit | №9 |

## 3. Модель загроз STRIDE

### Інвентаризація активів
| Актив | Тип | Рівень критичності | Обґрунтування |
|---|---|---|---|
| База даних (SQLite) | Дані | Критичний | Персональні дані студентів, оцінки |
| JWT Secret Key | Секрет | Критичний | Компрометація = повний доступ |
| Encryption Key | Секрет | Критичний | Втрата = втрата зашифрованих даних |
| API ендпоінти | Програмний | Високий | Точка входу для атак |
| Docker-контейнер | Інфраструктура | Високий | Середовище виконання |
| Логи аудиту (audit_log) | Дані | Середній | Докази для розслідувань |
| Файл .env | Секрет | Критичний | Всі секрети системи |

### Аналіз загроз
| STRIDE | Загроза для деканату | Контрзахід (реалізований) | Контрзахід (бажаний) |
|---|---|---|---|
| Spoofing — Підробка | Підробка JWT-токена | JWT з HMAC-SHA256 підписом (П5) | RS256 + Token Blacklist |
| Tampering — Зміна даних | Підміна оцінки через API | Pydantic валідація + RBAC (П5, П6) | MFA для зміни оцінок |
| Repudiation — Заперечення | Викладач заперечує зміну | Audit Log з 5W (П8) | Цифрові підписи логів |
| Info Disclosure — Витік | Читання email з БД | Field-Level Encryption (П7) | Шифрування всієї БД |
| Denial of Service | Перевантаження API | Rate Limiting (П6, Nginx П9) | Cloudflare WAF |
| Elevation of Privilege | Студент → admin | RBAC require_role() (П5) | ABAC + Permissions |
